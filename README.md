# SPACE INFORMATION VERIFICATION 
SpaceFactCheck – Verify Space & Universe Facts with Wikipedia Data
SpaceFactCheck is a simple tool that helps you verify space-related information using real-time data from Wikipedia. Whether you're curious about black holes, exoplanets, or the Big Bang, just enter your query and this tool will cross-check the information for accuracy using Wikipedia as a trusted source.

Features
✅ Verifies space and astronomy facts

📚 Uses live Wikipedia content for up-to-date accuracy

🧠 Ideal for students, educators, and space enthusiasts

 How It Works
Enter a query (e.g., "Are there more than 100 moons around Saturn?")

The tool fetches related Wikipedia content

It checks the factual accuracy of your query against the content

It provides a confidence-based verdict with source references
