## Overview  
SpaceFactCheck is a tool that helps you verify space and astronomy facts using live data from Wikipedia.  

Whether you're curious about black holes, exoplanets, or the Big Bang, you can enter a query and the tool will cross-check the information for accuracy in real-time.  

---

## Features  
- Verifies space and astronomy facts  
- Uses live Wikipedia content for up-to-date accuracy  
- Suitable for students, educators, and space enthusiasts  
- Provides a confidence-based verdict with source references  

---

## How It Works  
1. Enter a query (e.g., *"Are there more than 100 moons around Saturn?"*)  
2. The tool fetches relevant Wikipedia content  
3. It checks the factual accuracy of your query against the content  
4. You receive a verdict with supporting sources
